## Description (paste as-is — ~3,900 characters, keyword-optimized)

Prompt Vault is a free prompt manager for anyone who reuses the same prompts and text over and over. Save your best prompts once, then insert any of them into any text box on any website with a single keyboard shortcut. No more digging through a notes app, a Google Doc, or an old chat to find that one prompt that worked.

If you use AI tools every day, your best prompts are probably scattered across notes, docs and screenshots. Prompt Vault gives them one home — and makes them reachable in under a second, wherever you are typing.

★ SAVE YOUR PROMPTS ONCE, REUSE THEM EVERYWHERE
Build a personal prompt library: writing prompts, coding prompts, research prompts, email replies, canned support answers, code review checklists — anything you retype more than once. Organize with folders and tags so your library stays usable as it grows.

★ INSERT INTO ANY TEXT BOX, ON ANY SITE
Press Ctrl+Shift+Space (Cmd+Shift+Space on Mac) and a fast quick-search opens right on the page. Type a few letters, hit Enter, and the prompt is inserted where your cursor is. It works in AI chat boxes, email compose windows, forms, code review comments, support tools, CMS editors and social posts — standard inputs, textareas and rich text editors alike.

★ FIND THE RIGHT PROMPT INSTANTLY
Instant search across titles, prompt text, tags and shortcuts. Give a prompt a quick-search shortcut like ;fix or ;email and jump straight to it. The whole point is that retrieving a saved prompt should be faster than opening the document you kept it in.

★ SMART TEMPLATES WITH VARIABLES
Add {{variables}} to a prompt — like {{topic}} or {{tone}} — and Prompt Vault asks you to fill them in as you insert, so one template covers dozens of situations instead of ten near-identical copies.

★ STARTS USEFUL ON DAY ONE
Prompt Vault ships with a starter library of ready-to-use prompts across writing, coding and everyday tasks. Install it, press the shortcut, insert one — nothing to configure first.

★ 100% PRIVATE — NO ACCOUNT, NO TRACKING, NO SERVERS
Everything you save is stored locally in your own browser. There is no account to create, no sign-up, no analytics, no tracking and no server to send anything to. Your prompts never leave your device. Prompt Vault also requests no broad site access — it only touches the page you are on, at the moment you invoke it, which is why you will not see a scary "read and change all your data on all websites" warning when you install it.

★ YOUR DATA STAYS YOURS — FREE EXPORT AND IMPORT
Export your entire library to a JSON file and import it back any time, at no cost. Back it up, move it to another computer, or keep it in version control. Nobody should move a real library into a tool they cannot get their data back out of, so export and import are free forever.

WHO IT IS FOR
• Anyone who reuses AI prompts and is tired of copy-pasting from a doc
• Writers, marketers and founders with repeatable prompt workflows
• Developers who reuse code review, debugging and explanation prompts
• Support and sales teams with canned replies
• Students and researchers who reuse summarizing and explaining prompts

FREE PLAN
Up to 25 saved prompts, folders, tags, instant search, quick-insert on any site, and full JSON export and import.

PRO (COMING SOON)
Unlimited prompts, template variables, custom quick-search shortcuts, and optional cloud sync across devices.

Prompt Vault is intentionally small and fast. It does one thing — keep your prompts and put them where you type — and tries to do that better than a document ever could. If something is missing or does not work the way you expect, open an issue on the project page; feedback shapes what gets built next.
